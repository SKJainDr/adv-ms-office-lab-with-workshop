    Chapter 8: Advanced Workshop — 60 Hands-On Practice Tasks¶

    अध्याय 8: उन्नत कार्यशाला — 60 व्यावहारिक अभ्यास कार्य

    This chapter is a complete, self-contained task guide for the Advanced MS Office Workshop — 60 hands-on production tasks spread across 12 sections (5 tasks each), covering every unit of the VOI001 syllabus: MS Word, MS Excel, MS PowerPoint, Internet & Email, and MS Access. Each task is designed to take a focused student roughly 10–15 minutes of real typing, formatting, decorating or designing work — not a multiple-choice quiz question, but an actual small deliverable you build yourself in the real application.

    For every task you'll find: a short goal describing exactly what to produce, a picture of what the finished output should look like, and a numbered list of procedure hints to get you there. Nothing here replaces your own judgement — the hints tell you which commands to reach for, not the exact clicks, so there is room to explore the ribbon and find your own way to the same result.

    Use the companion Advanced MS Office Workshop Booklet to record your work, paste screenshots of each completed task, and answer the quiz and viva questions for each section.

    Note on translation

    Chapters 0–7 of this guide are presented bilingually (English and Hindi). Given the very large volume of original task content in this chapter (60 tasks across 12 sections), it is provided in English only at this time; a Hindi translation may be added in a future revision.

    WS1 Document Setup & Formatting Fundamentals¶

    Unit 2 — MS Word, §§1.2–1.5

    Five short document-formatting tasks covering typing, font/paragraph formatting, page setup and saving — the essential Word skills every later task builds on.

    Try it in the Workshop Booklet

    Record your work for this section — App/Tabs/Features used, your method, screenshots and results — in the Advanced MS Office Workshop Booklet.

    Task 1.1 — Format a College Notice¶

    Goal (~10–15 min): Type and format a one-page college notice announcing a workshop, with a centred bold title, a justified body paragraph, and a right-aligned date/signature block.

    ▶ Expected output — Task 1.1 (MS Word)

    Procedure / hints:

    1. Open a new blank Word document and set the page margins to Normal (2.54 cm all sides).
    2. Type the title 'NOTICE — Workshop on Digital Literacy' and centre-align it; set font to 16 pt, Bold.
    3. Below the title, type a 3–4 sentence announcement paragraph and justify it (Ctrl+J).
    4. On a new line, right-align 'Date: _' and 'Signature: _' (Ctrl+R).
    5. Save the file as Notice_YourRollNo.docx in your workshop folder.

    App, tabs & features used: Word — Home tab (Font group, Paragraph group, Alignment buttons); File > Save As

    Task 1.2 — Apply Font & Paragraph Styling¶

    Goal (~10–15 min): Take a plain, unformatted paragraph about 'Renewable Energy' and apply a Heading 1 style title, custom font colour, 1.5 line spacing, and a highlighted key term.

    ▶ Expected output — Task 1.2 (MS Word)

    Procedure / hints:

    1. Type a heading 'Renewable Energy Sources' and apply the built-in Heading 1 style from the Styles gallery.
    2. Type or paste a 4–5 sentence paragraph below the heading.
    3. Select the paragraph and set line spacing to 1.5 (Home > Paragraph > Line Spacing).
    4. Change the heading's font colour to a theme colour of your choice.
    5. Use the Text Highlight Color tool to highlight one key technical term in the paragraph.

    App, tabs & features used: Word — Home tab (Styles gallery, Font Color, Line Spacing, Text Highlight Color)

    Task 1.3 — Create a Multi-Level Numbered List¶

    Goal (~10–15 min): Build a two-level numbered agenda for a college fest, with 4 main items and 2–3 sub-items under two of them.

    ▶ Expected output — Task 1.3 (MS Word)

    Procedure / hints:

    1. Type the title 'Annual Fest 2026 — Agenda'.
    2. Start a numbered list (Home > Numbering) and type 4 main agenda items.
    3. Place the cursor at the end of item 2, press Enter, then press Tab to demote to a sub-level; type 2 sub-items.
    4. Repeat the demotion for item 3 with 2 sub-items of its own.
    5. Adjust the multilevel list style if needed via Home > Multilevel List gallery.

    App, tabs & features used: Word — Home tab (Numbering, Multilevel List, Increase/Decrease Indent)

    Task 1.4 — Insert and Position an Image with Caption¶

    Goal (~10–15 min): Insert a picture into a short report paragraph, wrap text around it, resize it proportionally, and add a numbered figure caption below it.

    ▶ Expected output — Task 1.4 (MS Word)

    Procedure / hints:

    1. Type a 3-sentence paragraph about your college campus.
    2. Insert > Pictures and choose any image from your files.
    3. Click the picture, use Layout Options to apply 'Square' or 'Tight' text wrapping.
    4. Drag a corner handle to resize the image proportionally to about 2 inches wide.
    5. Right-click the picture > Insert Caption, and set it to read 'Fig. 1 — '.

    App, tabs & features used: Word — Insert tab (Pictures); Picture Format tab (Layout Options, Size); References (Insert Caption)

    Task 1.5 — Set Page Margins, Orientation & Page Numbers¶

    Goal (~10–15 min): Format a short report's cover section: custom margins, a title block, and automatic page numbering in the footer starting from page 1.

    ▶ Expected output — Task 1.5 (MS Word)

    Procedure / hints:

    1. Layout tab > Margins > Custom Margins; set 1 inch on all sides.
    2. Type a report title block: title, your name, roll number, date — centred.
    3. Insert > Page Number > Bottom of Page > choose a centred style.
    4. Add 2–3 more blank pages (Ctrl+Enter for page breaks) to see the numbering increment.
    5. Confirm via Print Preview that margins and page numbers appear correctly.

    App, tabs & features used: Word — Layout tab (Margins); Insert tab (Page Number); File > Print (Preview)

    WS2 Tables, Lists & Page Layout¶

    Unit 2 — MS Word, §§1.9–1.11

    Five tasks on building and formatting tables, headers/footers, a table of contents, and footnotes — the layout tools needed for structured reports.

    Try it in the Workshop Booklet

    Record your work for this section — App/Tabs/Features used, your method, screenshots and results — in the Advanced MS Office Workshop Booklet.

    Task 2.1 — Create and Format a Class Timetable¶

    Goal (~10–15 min): Build a 6-day x 6-period timetable table with merged header cells, shaded header row, and centred text in every cell.

    ▶ Expected output — Task 2.1 (MS Word)

    Procedure / hints:

    1. Insert > Table; create a table with 7 columns and 7 rows.
    2. In row 1, type period numbers 1–6 across columns 2–7, and merge column 1 rows 1–2 for a 'Day/Period' label.
    3. Type day names (Mon–Sat) down column 1 and sample subjects into the grid.
    4. Select the header row and apply a background shade (Table Design > Shading).
    5. Select the whole table and centre-align all text both horizontally and vertically (Layout > Alignment).

    App, tabs & features used: Word — Insert tab (Table); Table Design tab (Shading, Borders); Table Layout tab (Merge Cells, Alignment)

    Task 2.2 — Design a Fee Structure Table¶

    Goal (~10–15 min): Create a fee-structure table with a Total row, alternating row shading, and appropriate right-aligned currency figures.

    ▶ Expected output — Task 2.2 (MS Word)

    Procedure / hints:

    1. Insert a table with 2 columns and 6 rows: 'Item' and 'Amount (₹)'.
    2. Fill in 4 fee items (Tuition, Library, Lab, Sports) with amounts.
    3. In the last row, type 'Total' and manually sum the amounts.
    4. Right-align all figures in the Amount column.
    5. Apply a built-in Table Style with alternating (banded) row shading from Table Design.

    App, tabs & features used: Word — Insert tab (Table); Table Design tab (Table Styles, Banded Rows); Layout Alignment

    Task 2.3 — Insert an Automatic Table of Contents¶

    Goal (~10–15 min): Apply heading styles to a 4-section outline and generate an automatic, clickable Table of Contents from those headings.

    ▶ Expected output — Task 2.3 (MS Word)

    Procedure / hints:

    1. Type 4 section headings (e.g. Introduction, Methodology, Results, Conclusion), each on its own line.
    2. Apply Heading 1 style to each, and add a short dummy paragraph under each heading.
    3. Place the cursor on a new page before the headings; go to References > Table of Contents.
    4. Choose an Automatic Table style from the gallery.
    5. Add one more heading further down, then right-click the TOC and 'Update Field' to confirm it refreshes.

    App, tabs & features used: Word — Home tab (Styles: Heading 1); References tab (Table of Contents, Update Table)

    Task 2.4 — Add a Running Header/Footer with Page Numbers¶

    Goal (~10–15 min): Add a header showing the document title on every page and a footer with 'Page X of Y' style numbering.

    ▶ Expected output — Task 2.4 (MS Word)

    Procedure / hints:

    1. Insert > Header > Edit Header; type your report title, left-aligned.
    2. Add a thin bottom border to the header text for a professional look.
    3. Insert > Footer > Edit Footer; type 'Page ' then Insert > Page Number > Current Position.
    4. Type ' of ' then Insert > Number of Pages to complete 'Page X of Y'.
    5. Close Header & Footer and scroll through multiple pages to confirm it repeats.

    App, tabs & features used: Word — Insert tab (Header, Footer, Page Number); Header & Footer Tools > Design tab

    Task 2.5 — Insert Footnotes for an Academic Paragraph¶

    Goal (~10–15 min): Write a short academic-style paragraph citing two sources using Word's automatic footnote numbering.

    ▶ Expected output — Task 2.5 (MS Word)

    Procedure / hints:

    1. Type a 3–4 sentence paragraph making two factual claims.
    2. Place the cursor right after the first claim; go to References > Insert Footnote.
    3. Type a source citation in the footnote area at the bottom of the page.
    4. Repeat for the second claim with a different source.
    5. Confirm the footnote markers (¹, ²) appear correctly in the body text and renumber automatically if you add a third.

    App, tabs & features used: Word — References tab (Insert Footnote)

    WS3 Mail Merge & Reference Tools¶

    Unit 2 — MS Word, §1.12; Unit 5 — integration with Excel data

    Five tasks walking through the complete mail-merge workflow end-to-end, plus hyperlinks/bookmarks and collaborative review tools.

    Try it in the Workshop Booklet

    Record your work for this section — App/Tabs/Features used, your method, screenshots and results — in the Advanced MS Office Workshop Booklet.

    Task 3.1 — Prepare a Mail-Merge Data Source¶

    Goal (~10–15 min): Build a small Excel table of 5 recipients (Name, Course, Fee Due) to be used as a mail-merge data source.

    ▶ Expected output — Task 3.1 (MS Excel)

    Procedure / hints:

    1. Open Excel and create column headers: Name, Course, FeeDue, DueDate.
    2. Enter 5 rows of sample student data under the headers.
    3. Format the header row in bold with a background fill.
    4. Format the FeeDue column as Currency.
    5. Save the file as MergeData.xlsx in your workshop folder.

    App, tabs & features used: Excel — Home tab (Font, Fill Color, Number Format); File > Save As

    Task 3.2 — Create a Mail-Merge Letter Template¶

    Goal (~10–15 min): Write a fee-reminder letter template in Word with merge placeholders for Name, Course and FeeDue.

    ▶ Expected output — Task 3.2 (MS Word)

    Procedure / hints:

    1. Open a new Word document and type a formal letter body with salutation and closing.
    2. Go to Mailings > Start Mail Merge > Letters.
    3. Mailings > Select Recipients > Use an Existing List, and browse to MergeData.xlsx.
    4. Place the cursor after 'Dear' and Mailings > Insert Merge Field > Name.
    5. Insert the Course and FeeDue merge fields at the appropriate points in the letter body.

    App, tabs & features used: Word — Mailings tab (Start Mail Merge, Select Recipients, Insert Merge Field)

    Task 3.3 — Complete the Merge & Preview Letters¶

    Goal (~10–15 min): Finish the mail merge, preview each personalised letter, and produce a single merged document containing all 5 letters.

    ▶ Expected output — Task 3.3 (MS Word)

    Procedure / hints:

    1. With the template and data source connected, click Mailings > Preview Results.
    2. Use the arrow buttons to page through and check each recipient's letter looks correct.
    3. Mailings > Finish & Merge > Edit Individual Documents > All.
    4. A new document opens with all 5 personalised letters, each on its own page — scroll through to verify.
    5. Save the merged output as MergedLetters.docx.

    App, tabs & features used: Word — Mailings tab (Preview Results, Finish & Merge)

    Task 3.4 — Insert Hyperlinks and Bookmarks¶

    Goal (~10–15 min): Add a clickable web hyperlink and an internal bookmark link (jump-to-section) inside a document.

    ▶ Expected output — Task 3.4 (MS Word)

    Procedure / hints:

    1. Type a sentence mentioning your university's website; select the university name.
    2. Insert > Link > Insert Link, and type the URL; confirm the text turns blue and underlined.
    3. Scroll to a heading further down; select it and Insert > Bookmark, name it 'ContactSection'.
    4. Scroll back up, select some text, and Insert > Link > Place in This Document > choose the bookmark.
    5. Ctrl+Click both links to confirm the web link opens a browser and the bookmark link jumps down the page.

    App, tabs & features used: Word — Insert tab (Link, Bookmark)

    Task 3.5 — Track Changes & Add Reviewer Comments¶

    Goal (~10–15 min): Turn on Track Changes, make a few edits to a paragraph, and add a reviewer comment — then accept/reject changes.

    ▶ Expected output — Task 3.5 (MS Word)

    Procedure / hints:

    1. Open a paragraph of text; go to Review > Track Changes > turn it on.
    2. Delete a sentence and add a new one — note the strikethrough and coloured insertion marks.
    3. Select a phrase and Review > New Comment; type a suggestion.
    4. Go to Review > Accept > Accept All Changes for half the document, leaving the rest marked.
    5. Review > Next to step through remaining changes/comments one at a time.

    App, tabs & features used: Word — Review tab (Track Changes, New Comment, Accept/Reject, Next)

    WS4 Advanced Formatting & Desktop Publishing¶

    Unit 2 — MS Word, §§1.8, 1.15

    Five tasks that push Word beyond plain text formatting into desktop-publishing territory: columns, WordArt, SmartArt, watermarks and PDF export.

    Try it in the Workshop Booklet

    Record your work for this section — App/Tabs/Features used, your method, screenshots and results — in the Advanced MS Office Workshop Booklet.

    Task 4.1 — Design a Two-Column Newsletter Layout¶

    Goal (~10–15 min): Lay out a short campus-newsletter article in two newspaper-style columns with a column break.

    ▶ Expected output — Task 4.1 (MS Word)

    Procedure / hints:

    1. Type a newsletter headline and a 6–8 sentence article body.
    2. Select the article body and go to Layout > Columns > Two.
    3. Position the cursor mid-article where you want the column to break, and Layout > Breaks > Column.
    4. Justify the body text for a cleaner newspaper look.
    5. Adjust column spacing via Layout > Columns > More Columns if the gap looks too tight or wide.

    App, tabs & features used: Word — Layout tab (Columns, Breaks); Home tab (Justify)

    Task 4.2 — Add a WordArt Headline and Drop Cap¶

    Goal (~10–15 min): Create a decorative WordArt-style headline plus a large drop-cap first letter for an article's opening paragraph.

    ▶ Expected output — Task 4.2 (MS Word)

    Procedure / hints:

    1. Insert > WordArt, choose a style, and type a headline such as 'CAMPUS TIMES'.
    2. Resize and position the WordArt at the top of the page.
    3. Below it, type an opening paragraph.
    4. Click inside the paragraph and go to Insert > Drop Cap > Dropped.
    5. Adjust the drop cap's font or number of lines it spans if needed (Drop Cap Options).

    App, tabs & features used: Word — Insert tab (WordArt, Drop Cap)

    Task 4.3 — Insert a SmartArt Process Diagram¶

    Goal (~10–15 min): Illustrate the college's admission process as a 4-step SmartArt process diagram with short labels.

    ▶ Expected output — Task 4.3 (MS Word)

    Procedure / hints:

    1. Insert > SmartArt > Process category, choose a basic left-to-right process layout.
    2. Type 4 short step labels (Enquiry, Apply, Interview, Admission) into the text pane.
    3. Select the SmartArt and change its colour scheme (SmartArt Design > Change Colors).
    4. Resize the SmartArt to fit neatly within the page margins.
    5. Add a one-line caption below explaining the diagram.

    App, tabs & features used: Word — Insert tab (SmartArt); SmartArt Design tab (Change Colors, Layouts)

    Task 4.4 — Apply a Watermark and Page Border¶

    Goal (~10–15 min): Mark a draft report with a diagonal 'DRAFT' watermark and add a decorative page border.

    ▶ Expected output — Task 4.4 (MS Word)

    Procedure / hints:

    1. Open or create a 1-page document with some body text.
    2. Design tab > Watermark > Custom Watermark > Text Watermark > type 'DRAFT'.
    3. Choose a light grey colour and diagonal layout, then apply.
    4. Design tab > Page Borders; choose a border style, width and colour.
    5. Apply the border to the Whole Document and confirm it doesn't overlap the text.

    App, tabs & features used: Word — Design tab (Watermark, Page Borders)

    Task 4.5 — Export the Finished Document to PDF¶

    Goal (~10–15 min): Take any finished document and export/save it as a PDF, then verify the formatting is preserved.

    ▶ Expected output — Task 4.5 (MS Word)

    Procedure / hints:

    1. Open your finished Notice or Report document from an earlier task.
    2. Go to File > Export > Create PDF/XPS Document (or File > Save As and choose PDF as the type).
    3. Choose a filename and location, keeping 'Standard' quality for print.
    4. Open the exported PDF in a PDF viewer and check fonts, images and layout all match the original.
    5. Note the PDF's file size compared to the original .docx file.

    App, tabs & features used: Word — File tab (Export > Create PDF/XPS, or Save As > PDF)

    WS5 Worksheet Basics, Formulas & Formatting¶

    Unit 3 — MS Excel, §§2.2–2.4

    Five tasks covering the Excel fundamentals: building a sheet, basic formulas, number formatting, absolute references, and sorting/filtering.

    Try it in the Workshop Booklet

    Record your work for this section — App/Tabs/Features used, your method, screenshots and results — in the Advanced MS Office Workshop Booklet.

    Task 5.1 — Build a Student Marks Sheet with SUM/AVERAGE¶

    Goal (~10–15 min): Create a 6-student marks sheet across 3 subjects, and compute each student's Total and Average using formulas.

    ▶ Expected output — Task 5.1 (MS Excel)

    Procedure / hints:

    1. Type headers: Name, Subject1, Subject2, Subject3, Total, Average across row 1.
    2. Enter 6 rows of sample names and marks (out of 100 each).
    3. In the Total column, type =SUM(B2:D2) and fill down for all rows.
    4. In the Average column, type =AVERAGE(B2:D2) and fill down.
    5. Format the Average column to show 1 decimal place.

    App, tabs & features used: Excel — Home tab (Number Format); Formulas — SUM(), AVERAGE(); fill handle

    Task 5.2 — Apply Cell Formatting & Number Formats¶

    Goal (~10–15 min): Format a small budget sheet with currency symbols, percentage figures, and clear borders/shading.

    ▶ Expected output — Task 5.2 (MS Excel)

    Procedure / hints:

    1. Build a 4-row budget list: Item, Amount, % of Total.
    2. Select the Amount column and apply the Currency number format (₹ symbol, 0 decimals).
    3. In the % of Total column, compute each item's share and apply Percentage format.
    4. Select the whole table and apply All Borders (Home > Borders).
    5. Shade the header row with a fill colour and bold white text.

    App, tabs & features used: Excel — Home tab (Number Format dropdown, Borders, Fill Color, Font)

    Task 5.3 — Use Relative vs Absolute Cell References¶

    Goal (~10–15 min): Compute each item's tax amount using a single fixed tax-rate cell, demonstrating the $ absolute-reference lock.

    ▶ Expected output — Task 5.3 (MS Excel)

    Procedure / hints:

    1. Set up a Price column for 5 items, and a single cell (e.g. G1) containing a tax rate like 18%.
    2. In the Tax column, type =B2*$G$1 for the first row, locking the rate cell with $ signs.
    3. Fill the formula down for all 5 items and confirm every row correctly references G1.
    4. Try removing the $ signs and re-filling down to see the (incorrect) result for comparison.
    5. Restore the absolute reference and add a Total row summing the Tax column.

    App, tabs & features used: Excel — Formulas (relative vs $absolute$ references); F4 key to toggle reference type

    Task 5.4 — Sort and Filter a Data List¶

    Goal (~10–15 min): Sort a list of 8 products by price, then apply a filter to show only items above a chosen price threshold.

    ▶ Expected output — Task 5.4 (MS Excel)

    Procedure / hints:

    1. Build a list of 8 products with Name, Category and Price columns.
    2. Select the data range and Data > Sort > sort by Price, Largest to Smallest.
    3. Select the header row and Data > Filter to add dropdown filter arrows.
    4. Click the Price column's filter arrow > Number Filters > Greater Than, and enter a threshold.
    5. Confirm only matching rows remain visible, then clear the filter to restore the full list.

    App, tabs & features used: Excel — Data tab (Sort, Filter, Number Filters)

    Task 5.5 — Freeze Panes & Set Up Printing¶

    Goal (~10–15 min): Freeze the header row of a 30-row sheet so it stays visible while scrolling, and configure Print Setup to fit on one page.

    ▶ Expected output — Task 5.5 (MS Excel)

    Procedure / hints:

    1. Open or extend a sheet to about 30 data rows with a header row at the top.
    2. Click cell A2, then View > Freeze Panes > Freeze Top Row.
    3. Scroll down and confirm the header row stays fixed at the top.
    4. Go to Page Layout > Print Titles and set row 1 to repeat at the top of every printed page.
    5. Page Layout > Size and Scale to Fit > set Width to 1 page, and preview via File > Print.

    App, tabs & features used: Excel — View tab (Freeze Panes); Page Layout tab (Print Titles, Scale to Fit)

    WS6 Functions, Data Tools & Conditional Formatting¶

    Unit 3 — MS Excel, §§2.5–2.7

    Five tasks on logical/lookup functions, conditional formatting, data validation, and data-cleaning tools.

    Try it in the Workshop Booklet

    Record your work for this section — App/Tabs/Features used, your method, screenshots and results — in the Advanced MS Office Workshop Booklet.

    Task 6.1 — Grade Students with IF/Nested IF¶

    Goal (~10–15 min): Assign letter grades (A/B/C/F) to 8 students' average marks using a nested IF formula.

    ▶ Expected output — Task 6.1 (MS Excel)

    Procedure / hints:

    1. Set up Name and Average columns for 8 students.
    2. In the Grade column, type a nested IF: =IF(B2>=90,"A",IF(B2>=75,"B",IF(B2>=50,"C","F"))).
    3. Fill the formula down for all 8 students.
    4. Test the boundary cases by editing one average to exactly 90 and one to exactly 49.
    5. Apply bold red font to any cell showing an 'F' grade.

    App, tabs & features used: Excel — Formulas — IF() (nested); Home tab (Conditional font formatting)

    Task 6.2 — Look Up Values with VLOOKUP/XLOOKUP¶

    Goal (~10–15 min): Use VLOOKUP (or XLOOKUP) to pull a product's price from a lookup table based on a typed product code.
