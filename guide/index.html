    Advanced MS Office Lab — User Guide¶

    Welcome! This is the full lecture-note companion to the Advanced MS Office Lab — the 14-section, 100-task interactive lab covering MS Word, MS Excel, MS PowerPoint, the Internet & Email, and MS Access, built from the VOI001 Introduction of MS-Office syllabus.

    Use the navigation tabs above to read straight through like a textbook, or use the table below to jump directly to the chapter that matches whichever lab section you're currently working on.

    Which chapter matches which lab section?¶

    Lab section (in the app) Read this chapter
    Word Foundations MS Word — starts at 1.1 Introduction to Word and Screen Layout
    Fonts, Paragraphs & Styles MS Word — 1.5 Formatting Text and Paragraphs
    Lists, Graphics & Tables MS Word — 1.7 Bullets and Numbered Lists onward
    Headers, Mail Merge & Proofing MS Word — 1.11 Header and Footer onward
    Word Challenge MS Word — 1.12 Mail Merge, plus the full chapter
    Excel Foundations MS Excel — 2.1 Introduction to the Excel Environment
    Formulas & Functions MS Excel — 2.4 Performing Calculations with Formulas and Functions
    Sorting, Charts & PivotTables MS Excel — 2.5 Sorting and Filtering Data onward
    Excel: Charts & Trendlines MS Excel — 2.6 Creating and Formatting Charts
    Excel Challenge MS Excel — 2.7 Advanced List Management, plus the full chapter
    PowerPoint Foundations MS PowerPoint — 3.1 Setting up the PowerPoint Environment
    Objects, Media & SmartArt MS PowerPoint — 3.5 Working with Objects onward
    Animation, Transitions & Delivery MS PowerPoint — 3.9 Animation and Slide Transition onward
    PowerPoint Challenge MS PowerPoint — 3.6 Hyperlinks and Action Buttons, plus the full chapter

    All chapters¶

    1. Getting Started — installing MS-Office, opening applications, saving and opening files
    2. MS Word — the complete Word chapter (screen layout through mail merge, proofing and printing)
    3. MS Excel — the complete Excel chapter (formulas, sorting/filtering, charts, PivotTables)
    4. MS PowerPoint — the complete PowerPoint chapter (objects, animation, delivery)
    5. Internet, WWW & Email — browsers, safe use of the internet, email accounts and attachments
    6. MS Access — databases, tables, queries, forms and reports
    7. Integration & Careers — how the five tools work together, and career value
    8. Keyboard Shortcuts — the full shortcut reference for all five applications
    9. Glossary — key terms defined
    10. Troubleshooting — fixes for common installation, file, and application issues
    11. Practice Questions — MCQs, short-answer and practical/long-answer questions for revision
